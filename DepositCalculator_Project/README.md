# Deposit Calculator Automation

## 🔹 Overview
This project automates the testing of a Deposit Calculator application using Selenium WebDriver with Java. It focuses on validating interest calculation and maturity values using a data-driven testing approach.

---

## 🔹 Objective
- Validate deposit amount calculations  
- Verify interest and maturity amount  
- Test multiple input combinations using data-driven testing  

---

## 🔹 Tech Stack
- Java  
- Selenium WebDriver  
- TestNG  
- Excel (Test Data - Data Driven Testing)  

---

## 🔹 Key Features
- Data-driven testing using external test data  
- Automated validation of calculation results  
- Reusable test logic for multiple datasets  
- Covers positive and negative test scenarios  

---

## 🔹 Test Scenarios Covered
- Valid deposit inputs  
- Different time durations  
- Interest rate variations  
- Boundary value testing  
- Invalid inputs (negative, empty values)  

---

## 🔹 How to Run
1. Import project into IntelliJ / Eclipse  
2. Install required dependencies  
3. Run test class or TestNG XML  
4. View execution results  

---

## 🔹 Key Learning
- Implementation of Data-Driven Testing  
- Handling multiple test datasets  
- Automating calculation validation using Selenium
