🔹 Overview
This project demonstrates data-driven testing for a Deposit Calculator application. Multiple input combinations are tested using structured test data to validate calculation accuracy.

🔹 Objective
Validate deposit calculation logic
Test multiple input combinations using external test data
Ensure correct interest and maturity values

🔹 Approach
Designed test cases using Excel
Implemented data-driven testing concept
Used multiple datasets to validate outputs

🔹 Test Scenarios Covered
Valid input combinations
Boundary values
Invalid inputs
Interest calculation validation

🔹 Tools Used
Excel (Test Data & Test Cases)
Manual Testing Approach

🔹 Key Learning
Data-driven testing implementation
Test data management
Edge case validation
