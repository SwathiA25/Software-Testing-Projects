
# Loan Calculator Automation

## 🔹 Overview
This project automates the testing of a Loan Calculator application using Selenium WebDriver with Java. It validates EMI calculations based on different loan inputs.

---

## 🔹 Objective
- Verify EMI calculation accuracy  
- Validate loan input fields  
- Ensure correct output generation  

---

## 🔹 Tech Stack
- Java  
- Selenium WebDriver  
- TestNG  

---

## 🔹 Key Features
- Automated testing of loan calculation logic  
- Validation of EMI results  
- Covers multiple input combinations  
- Handles edge cases and invalid inputs  

---

## 🔹 Test Scenarios Covered
- Valid loan inputs (amount, tenure, interest)  
- Boundary values (minimum and maximum limits)  
- Invalid inputs (negative values, empty fields)  
- EMI calculation validation  

---

## 🔹 How to Run
1. Import project into IntelliJ / Eclipse  
2. Configure dependencies (if any)  
3. Run test class  
4. Check results in console/output  

---

## 🔹 Key Learning
- Automation of financial calculations  
- Validation of dynamic UI results  
- Writing reusable Selenium test scripts
